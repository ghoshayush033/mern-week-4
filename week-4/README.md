# Week 4 Capstone - MERN E-Commerce Web Application

A full-stack, production-ready E-Commerce Web Application built with the **MERN Stack** (MongoDB, Express.js, React, Node.js), featuring JWT authentication, role-based access control, cart management, product catalog with search/filter, and an interactive Admin Dashboard.

## Key Features
- **Authentication**: JWT token-based authentication and secure role-based access (User/Admin).
- **Product Catalog**: Live search, category filtering, stock updates, and responsive card layouts.
- **Cart & Checkout**: Real-time quantity adjustments, price calculations, and simulated payment checkout flow.
- **Admin Dashboard**: Comprehensive order status updates (Pending, Shipped, Delivered) and product CRUD console.

## Setup Instructions
1. Backend: Navigate to `/server`, run `npm install`, set environment variables in `.env`, and start with `npm run dev`.
2. Frontend: Navigate to `/client`, run `npm install`, and launch with `npm run dev`.
